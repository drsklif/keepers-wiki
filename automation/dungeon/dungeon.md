# Автоматизация подземелья

## Цель

Забирать сундуки коридоров и крутить каменоломню без открытия окна подземелья. Результаты пишутся в лог, tooltip кнопки и `localStorage`.

## Сокровища (коридоры)

Источник: `DungeonPage`, `user.dungeon`, `CFGUtil.getDungeonNextOpenTime`.

Четыре коридора: HIT золотой (каждый день), F жаркий (пн/чт/вс), N зелёный (вт/пт/вс), W затопленный (ср/сб/вс). День здесь **игровой**: клиент считает его через `TimeUtil._getMoscowTime` + `getDungeonNextOpenTime`, а не через часовой пояс браузера. `user.gmt` на расписание коридоров не влияет (он сдвигает окна энергии).

Итоги сундуков/каменоломни сбрасываются вместе с этим циклом: ключ — `dungeon.HIT.lot` (серверная метка открытия текущего дня), запасной вариант — тот же `getDungeonNextOpenTime("HIT")`.

Состояние `user.dungeon.b1..b4` / `UserUtil.getDungeonByType(type)`:

- `s === 0` — закрыт, следующее открытие по расписанию.
- `s === 1` — бой с боссом (скрипт **не** бьёт, `DungeonBattle` не шлётся).
- `s === 2` — сундук. Можно открыть, если `lcot` пустой или прошли сутки: `DungeonChestOpen { type }`.

Награда в ответе `drop.list` (золото, предметы, карты). Клиент ещё вызывает `processChestDrop` и попап сундука; скрипт применяет дроп без UI.

## Каменоломня

Источник: `StonesPage`, `user.s_cave`, `cfg.cfgStones.tries` (8 в сутки).

Поле 8×8, клетки 1..64. Одновременно один поиск.

- Свободная клетка: `StonesCaveStartDig { cell }` — `et` ≈ now + 10 мин (брать из модели, не хардкодить).
- Когда `et <= now`: `StonesCaveSearchCompleted` — камень `C/H/F/N/W` или пыль `D` (`cell.v`).
- Пока поиск идёт, новая клетка даёт ошибку 2. Попытки кончились — код 3.

Не используются: `StonesCaveBoostSearch` (ускорение за кристаллы), `StonesCaveResetTries` (доп. попытки).

Попытки: `s_cave.t.l` осталось, потраченные считаются по клеткам `s_cave.l` за текущий игровой день (и `s_cave.t.t`, если сервер его ведёт). Находки — с поля `s_cave.l` (и ручные, и скрипт), не из лога скрипта. Сброс попыток: `s_cave.rt`.

## Требования к скрипту

- Tampermonkey-модуль KeepersHelper.
- Без окон подземелья и без попапов награды.
- Переключатель «Подземелье» в оверлее, по умолчанию включён.
- Итоги текущего игрового дня — tooltip, консоль `[AutoDungeon]`, `keepersHelper.dungeon.results` (поле `period` = timestamp начала суток в игре).
