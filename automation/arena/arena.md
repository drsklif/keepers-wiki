# Автоматизация арены

## Цель

Бить арену по таймеру награды (~2 часа), не открывая окно арены и не покупая доп. попытки за кристаллы.

## Как устроено в клиенте

Источник: `ArenaPage`, `UserUtil.getDeckCardsPower`, `user.arena`.

- Список из 3 соперников: `user.arena.entry.enemies`. Первый — самый слабый (`u.pwr`).
- Своя мощь для сравнения: `UserUtil.getDeckCardsPower()` — активная боевая колода (`cards.decks[cards.adx]`). На экране нападения клиент показывает именно её; защитная `getArenaDeckCardsPower()` для автобоя не используется.
- Попытки: `user.arena.attempts`. На экране «из N» = `attempts.max`, плюс `premium.v.cfg.bonus.arena` если VIP активен. Без VIP лимит 5 в сутки.
- После боя `entry.rt` ≈ now + 2 часа («До получения награды»). Клиент позволяет бить раньше, если попытки ещё есть; скрипт ждёт `rt`.
- Автобой: `ArenaBattle` `{ enemy, auto: 1 }` за 5 кристаллов (`{ t: 1, v: 5 }`), затем `ArenaBattleEnd`. Исход боя не важен.
- Обновление списка: `ArenaEnemiesUpdate`. Просмотр колоды (`ArenaEntryDeck`) для автобоя не нужен.
- Покупка попыток: `ArenaBuyAttempts` — скрипт её не шлёт.

## Правила выбора

1. Всегда первый из трёх.
2. Брать, если его мощь ≤ своя × 1.10 (240к → до 264к включительно).
3. Если первый сильнее — обновить список и повторить.

## Требования к скрипту

- Tampermonkey-модуль KeepersHelper.
- Без окон арены и без `BattlePage.showArenaEnd`.
- Переключатель «Арена» в оверлее, по умолчанию включён, состояние в `localStorage`.
- Не открывать и не закрывать попапы. Если уже идёт обычный бой (`BATTLE`) — подождать.
